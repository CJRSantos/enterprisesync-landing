## 🚀 About the Product

**EnterpriseSync Core™** is an enterprise-grade fullstack boilerplate bridging:
- **Backend API**: Modular **NestJS 10** with dual database support (zero-config SQLite + Dockerized PostgreSQL 16), JWT auth, cryptographic Google Sign-In, and transactional outbox sync.
- **Mobile Client**: **Flutter 3.38** with Clean Architecture, BLoC 9.1 state management, and hardware-backed Keystore/Keychain encryption.
